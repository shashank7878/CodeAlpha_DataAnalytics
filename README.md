# Web Scraping & Data Cleaning Internship Task

This project was completed as part of my first internship task focused on Web Scraping and Data Preprocessing using Python.

## Project Objective

The main objective of this task was to understand how raw web data is collected, processed, and converted into a clean structured dataset suitable for data analysis.

## Tasks Performed

* Collected and worked with a Flipkart mobile dataset.
* Used Python libraries such as Pandas for data handling and preprocessing.
* Identified missing/null values present in the dataset.
* Removed entire rows containing empty values to improve data quality.
* Cleaned and organized the dataset for further analysis and visualization.

## Tools & Technologies Used

* Python
* Pandas
* CSV / Excel Handling
* Data Cleaning Techniques

## Outcome

Successfully cleaned the dataset by removing inconsistent records and prepared a structured dataset containing valid entries only. This task helped me gain practical experience in handling real-world data preprocessing workflows used in Data Analytics projects.
